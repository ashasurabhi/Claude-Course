---
name: status-report-skill
description: Writes the daily status report from a raw activity log, in a fixed layout.
---

Write the report with these sections, in this order:

1. Headline: one sentence on the day's main result.
2. Completed: bullet list of finished items, with counts where the log gives them.
3. In progress: bullet list, with the owner in brackets.
4. Blocked: anything waiting on someone else, with the name of that person.
5. Tomorrow: the top three planned items.

Use only facts from the activity log. If a section has nothing to report, write "None" under its heading.
Output only the report itself. Do not describe what you are doing, do not
mention the skill or these instructions, and do not say where the report was saved.
Start with the first section heading.
